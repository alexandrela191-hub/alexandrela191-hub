# Привет! Я Александр 👋

Разрабатываю прикладные инструменты автоматизации на Python: OCR, обработку документов, сбор структурированных данных и экспорт результатов в Excel.

[Открыть страницу-портфолио](https://alexandrela191-hub.github.io/alexandrela191-hub/)

## Проекты

### [OCR Studio](https://github.com/alexandrela191-hub/OCR-Studio)

Windows-приложение для пакетного распознавания документов, извлечения ФИО и номеров помещений, ручной проверки спорных результатов и автоматизации рабочего процесса.

**Стек:** Python, Tesseract OCR, OpenCV, Tkinter, Selenium, NumPy, OpenPyXL.

### [RUMS Rooms Exporter](https://github.com/alexandrela191-hub/RUMS-Rooms-Exporter)

Инструмент поиска московского МКД по адресу или кадастровому номеру с выгрузкой сведений о помещениях в Excel. Поддерживает параллельные запросы, повторные попытки и локальный кэш.

**Стек:** Python, pynspd, OpenPyXL, concurrent.futures.
