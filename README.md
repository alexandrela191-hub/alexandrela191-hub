# Автоматизация документов • OCR • Обработка данных

Разрабатываю инструменты на Python для распознавания документов, проверки извлечённых данных и автоматизации повторяющихся операций. Ищу работу в OCR, document automation и обработке данных; рассматриваю удалённый и гибридный формат.

## Что я сделал

- **Обработка документов:** пакетное распознавание PDF и изображений, извлечение ФИО и номеров помещений, обучаемые зоны и ручная проверка результатов.
- **Автоматизация процесса:** подготовка подтверждённых файлов к дальнейшей обработке и автоматизация рабочего сценария через Chrome/Selenium.
- **Обработка данных:** поиск объектов по адресу или кадастровому номеру, проверка соответствия, получение сведений о помещениях и формирование Excel-отчёта.
- **Устойчивость и проверяемость:** восстановление сессии в OCR Studio, безопасное сохранение и тесты в демо, кэш и повторные запросы в Rooms Exporter.

### Как связаны два OCR-проекта

**OCR Studio** показывает рабочее приложение с интерфейсом, шаблонами и автоматизацией через Selenium. **OCR demo** — отдельная реализация основных этапов для знакомства с подходом. Демо создано по мотивам v43.17.49; оно не является копией текущего релиза v43.17.73. Команда mock-robot формирует локальный план действий без подключения к рабочему порталу.

## Технологии в проектах

Python, Tesseract OCR, OpenCV, Pillow, Poppler/pdf2image, Tkinter, Selenium, NumPy, OpenPyXL, pynspd. Конкретные зависимости и требования указаны в каждом репозитории.

Рабочие документы, данные авторизации, локальные настройки и результаты обработки в репозитории не включены.
